# Features

## Completed

- Public storefront home, product list, search/filter, product detail.
- Customer registration, login, profile, saved addresses.
- Cart with localStorage.
- Checkout with server-side price and stock validation.
- Customer order list and order detail.
- Admin product, brand, category management.
- Serial inventory management.
- Order approval, cancellation, shipping, completion workflow.
- Serial assignment and unassignment correction rules.
- Warranty lookup by Serial.
- Warranty ticket management for admin/technician.
- Dashboard and report APIs/pages.
- Wishlist for customers.
- Product reviews with pending moderation status.
- Static warranty policy, shipping policy, contact, and showroom pages.

## Partially Completed

- Product reviews can be submitted and approved reviews are shown, but no admin moderation page exists yet.
- Wishlist is customer-facing and simple.
- Reports are table/bar based without external chart libraries.
- Payment is simulated with COD or bank transfer selection only.

## Intentionally Not Implemented

- Real payment gateway.
- Email/SMS sending.
- File upload.
- Product return/refund stock workflow.
- Warranty attachment management.
- Admin audit logs.
- Advanced promotion/voucher engine.
